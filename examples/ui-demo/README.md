# UI Demo Example

A minimal UI-focused project scaffold for testing Control tree inspection.

## Purpose

- Validate dock and editor workflows in UI-heavy scenes.
- Test node property inspection for labels, buttons, and containers.
- Provide a simple foundation for runtime state mutation experiments.

## Suggested next steps

1. Add the addon to the project.
2. Build a `Control`-based main scene.
3. Use the MCP runtime tools to inspect visible UI state during play mode.
