# Minimal 2D Example

A tiny Godot 4 project scaffold for validating editor connectivity.

## Purpose

- Confirm the addon can be copied into a fresh 2D project.
- Test editor-side tools such as scene discovery and project status.
- Serve as a safe sandbox for prompt experiments.

## Suggested next steps

1. Add the `addons/godot_universal_mcp` directory to this project.
2. Enable the plugin in **Project Settings > Plugins**.
3. Create a simple 2D scene and verify `editor.get_scene_tree` from your MCP client.
