# Minimal 3D Example

A starter Godot 4 project for validating 3D-oriented workflows.

## Purpose

- Test the addon in a clean 3D project.
- Exercise node inspection against cameras, lights, and meshes.
- Provide a baseline for future runtime debugging examples.

## Suggested next steps

1. Copy in the addon directory.
2. Enable the plugin.
3. Create a `Node3D` root scene with a camera and mesh.
4. Use your MCP client to inspect scene structure and properties.
