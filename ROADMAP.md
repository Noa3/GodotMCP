# Roadmap

## Near-term priorities

- Stabilize the TypeScript MCP server and tool schemas.
- Expand editor and runtime bridge coverage for common Godot workflows.
- Add richer diagnostics, log streaming, and structured error reporting.
- Provide validated setup flows for VS Code, GitHub Copilot, and other MCP-capable clients.

## Planned features

- Scene diff and patch assistance.
- Resource import and asset inspection helpers.
- Safer runtime mutation guards and permission prompts.
- Automated compatibility tests against multiple Godot 4.x versions.
- Optional transport modes beyond localhost TCP.

## Nice to have

- Packaged Godot asset library distribution.
- Example AI workflows for level design, UI iteration, and debugging.
- Deeper performance profiling and screenshot/video capture support.
